# 커뮤니티 배포용 글 (초안)

기준 데이터: 2026-09-23 스냅샷. **올리기 전에 숫자를 그날 값으로 바꿀 것.**

---

## 먼저 읽을 것 — 이걸 안 지키면 삭제·차단됩니다

한국 주식 커뮤니티는 링크 홍보에 매우 민감합니다. 아래를 지켜야 합니다.

1. **글 자체로 완결되어야 합니다.** 링크를 눌러야 알 수 있는 구조로 쓰면 광고로 읽힙니다. 숫자와 결론을 본문에 다 넣고, 링크는 "나머지 종목은 여기" 용도로만 맨 아래 한 번.
2. **첫 글에는 링크를 아예 넣지 마세요.** 계정이 새 계정이면 더더욱. 두세 번 정보성 글을 올려 평판을 만든 다음 링크를 붙입니다.
3. **하루에 한 군데만.** 같은 글을 여러 커뮤니티에 동시에 도배하면 전부 걸립니다.
4. **각 사이트 규정 확인.** 네이버 카페는 대부분 카페 규정에 외부링크 금지가 명시돼 있습니다. 카페는 매니저에게 먼저 문의하는 게 안전합니다.
5. **매수/매도 추천 표현 금지.** "사야 한다", "목표가" 같은 표현은 유사투자자문으로 문제가 될 수 있습니다. 전부 "데이터는 이렇다" 로만 씁니다.

추천 순서: **디시 주식갤 → 클리앙 → (평판 생긴 뒤) 네이버 카페**

## 글 1 — 디시 주식갤 / 클리앙용. 가장 강한 후크

제목 후보
- `외국인이 지금 한국주식에서 얼마에 물려있는지 계산해봄`
- `현대로템 외국인 평균단가 18.8만, 현재가 11.6만`

본문

```
회전율 가중 기준가격이라는 게 있는데
(Grinblatt & Han 2005, 학계에서 투자자 평균 매입가 추정할 때 쓰는 방법)

매일 거래량으로 이전 보유분이 얼마나 교체됐는지를 가중해서
"지금 들고 있는 사람들이 평균 얼마에 샀는지"를 역산하는 겁니다.

이걸 외국인 순매수 데이터에 적용해서 계산해봤습니다.
시총 3조 이상 종목 중에 외국인 평단 대비 괴리가 큰 것들:

[외국인이 물려있는 쪽]

에코프로비엠 현재 105,500 / 외인평단 149,681  (-41.9%)
하이브      현재 157,700 / 외인평단 221,203  (-40.3%)
한국전력    현재  30,450 / 외인평단  42,444  (-39.4%)
카카오      현재  33,800 / 외인평단  46,880  (-38.7%)
에코프로    현재  80,100 / 외인평단 110,733  (-38.2%)
현대차      현재 357,000 / 외인평단 466,605  (-30.7%)
LG화학      현재 253,000 / 외인평단 326,224  (-28.9%)

[외국인이 벌어놓은 쪽]
삼성전자우  현재 222,000 / 외인평단 150,139  (+32.4%)
삼성전자    현재 286,500 / 외인평단 201,476  (+29.7%)

여기서 재밌는 게, 벌어놓은 쪽에서 외국인이 지금 팔고 있습니다.
최근 1개월 외국인 순매도 1위 SK하이닉스 -8.6조, 2위 삼성전자 -2.1조.
둘 다 평단 대비 +29% 구간입니다.

반대로 현대로템은 -61% 물려있는데 순매도(-229억)입니다. 손절 중.

참고로 이 계산은 추정치입니다. 외국인 전체를 한 명으로 보고
공시된 일별 순매수 금액을 회전율로 가중한 값이라
실제 개별 펀드 단가랑는 당연히 다릅니다.
방향성 참고용으로만.
```

## 글 2 — 기타법인 = 자사주 매입 추적. 아무도 안 다루는 각도

제목 후보
- `기타법인 순매수 보면 자사주 매입 규모가 보입니다`
- `삼전 하이닉스 기타법인 순매수가 매일 이상하게 일정한 이유`

본문

```
투자자별 매매동향 볼 때 보통 외국인/기관만 보고 개인은 반대로 읽고
기타법인은 그냥 넘기는데, 기타법인이 생각보다 정보량이 있습니다.

기타법인 = 금융회사가 아닌 일반 법인입니다. 여기에 들어가는 게
 - 자사주 매입
 - 계열사 지분 취득
 - M&A 목적 장내매집
즉 KRX 분류에서 내부자에 가장 가까운 매수 주체입니다.

최근 9영업일 SK하이닉스 기타법인 일별 순매수(억원):
 09/15  +11,196
 09/16  +11,285
 09/17  +11,638
 09/18  +11,324
 09/21  +11,092
 09/22  +11,281
 09/23  +11,397

매일 1.1조씩, 편차가 3% 이내입니다.
일반적인 수급은 이렇게 안 움직입니다. 날마다 몇 배씩 튑니다.
이렇게 일정한 건 프로그램으로 기계적으로 사고 있다는 뜻이고,
사실상 진행 중인 자사주 매입 프로그램입니다.

삼성전자도 같은 패턴 (매일 +5,000억 내외, 편차 2%).

그래서 최근 1개월 합계가 이렇게 됩니다:
 SK하이닉스  기타법인 +22.0조 / 외국인 -8.6조
 삼성전자    기타법인 +10.2조 / 외국인 -2.1조

외국인이 파는 물량을 회사가 받고 있는 구조입니다.
"외국인 대량 순매도"만 보면 악재로 읽히지만
받아주는 주체가 회사 자신이면 해석이 달라집니다.

기타법인 순매수 상위 (1개월, 대형주 제외):
 DL이앤씨    +1,211억 (시총 3.1조 → 시총의 3.9%)
 셀트리온    +1,045억
 롯데쇼핑    +1,010억 (시총 3.0조 → 3.4%)
 LG          +932억
 현대제철    +874억
 현대백화점  +841억 (시총 2.1조 → 4.0%)

시총 대비 비중으로 보면 롯데쇼핑 현대백화점 DL이앤씨가 눈에 띕니다.
셋 다 외국인은 순매도인데 기타법인이 받고 있습니다.

주의: 기타법인에는 자사주 말고 단순 일반법인 거래도 섞입니다.
자사주 매입인지 확인하려면 DART 공시를 봐야 합니다.
여기서는 "볼 곳을 찾는" 용도입니다.
```

## 글 3 — 짧은 버전. 반응 테스트용. 댓글 유도형

```
외국인 평균단가 대비 현재가, 시총 상위 정리해봤습니다

+  삼성전자      +29.7%  (평단 201,476)
+  SK하이닉스    +29.4%  (평단 1,314,878)
+  S-Oil         +29.1%  (평단 110,911)
-  현대차        -30.7%  (평단 466,605)
-  카카오        -38.7%  (평단  46,880)
-  한국전력      -39.4%  (평단  42,444)
-  하이브        -40.3%  (평단 221,203)
-  현대로템      -61.6%  (평단 188,639)

회전율 가중(Grinblatt-Han) 추정이라 정확한 값은 아니고
외국인 전체를 한 명으로 본 근사치입니다.

찾아보고 싶은 종목 있으면 댓글에 적어주세요, 계산해서 답변드립니다.
```

> 마지막 줄이 핵심입니다. 댓글이 달리면 글이 상단에 유지되고,
> 답변하면서 자연스럽게 링크를 줄 수 있습니다. 본문 링크보다 이게 안전합니다.
